# Background Remover

Локальное Windows-приложение для пакетного удаления фона с фотографий людей. RGB исходника сохраняется, меняется alpha-канал; результат — RGBA PNG исходного разрешения. Файлы никуда не отправляются.

## Требования

- Windows 11 x64, Python 3.11/3.12 x64;
- NVIDIA GeForce RTX 5070 с 12 GB VRAM;
- актуальный NVIDIA Driver (для CUDA 13.0 на Windows нужен драйвер не ниже 580.88);
- интернет только при первой установке для Python-пакетов и весов модели.

## Установка и запуск

1. Запустите `setup.bat` двойным кликом. Он создаст `.venv`, установит CUDA-сборку PyTorch, зависимости, скачает модель и выполнит настоящий smoke test.
2. Запускайте приложение через `Background Remover.bat`.
3. Если установка не завершилась, запустите `diagnose.bat` и сохраните вывод.

Используется `torch 2.11.0 + CUDA 13.0` и `torchvision 0.26.0`. Основная модель — `ZhengPeng7/BiRefNet_HR-matting` revision `5d6b6f8`; дополнительная — `ZhengPeng7/BiRefNet_dynamic-matting` revision `074df54`; обе MIT. PyTorch имеет BSD-style license, Transformers — Apache-2.0, PySide6 — LGPLv3/GPLv3/commercial. Перед коммерческим распространением самостоятельно проверьте тексты лицензий всех поставляемых бинарников.

## Работа

Выберите исходную папку и нажмите «Начать обработку». Результат автоматически создаётся рядом как `<имя исходной папки>_result`. Приложение показывает только выбор папки, количество файлов, Start/Stop и локальную историю обработок.

Кнопка «Остановить» ждёт завершения текущего файла и сохраняет его. Повторный запуск автоматически продолжает партию по `run.csv`; готовые файлы не вычисляются заново. Исходники никогда не перезаписываются. Подпапки сохраняются, поэтому одинаковые имена не конфликтуют.

Production-результат:

```text
<source>_result/
  ready/             # автоматически пригодные результаты
  review/            # PNG создан, но требуется ручная проверка
  failed/            # технические ошибки
  report.csv
  summary.json
```

Диагностический запуск движка может использовать `debug_output/` с `previews/` и `contact_sheet/contact_sheet.png`; основной GUI не создаёт их для всей партии.

На верхнем уровне используются только `READY`, `REVIEW`, `FAILED`. Причины Review (`edge_halo`, `mask_issue`, `missing_body_part`, `cropped_source`, `multiple_people_uncertain` и другие) записываются в CSV. Независимый SSD-Lite person detector проверяет соответствие оригинала и alpha, включая несколько людей. Edge decontamination восстанавливает RGB полупрозрачных пикселей, не размывая и не сжимая alpha. Тяжёлая secondary BiRefNet-модель остаётся выключенной по умолчанию.

## Диагностика и ограничения

GUI показывает Windows, Python, PyTorch, CUDA runtime, GPU, VRAM, модель и precision. При обнаруженной RTX приложение не переходит на CPU молча: CPU можно подтвердить явно. CUDA OOM очищает cache и повторяет текущий файл; повторный сбой маршрутизируется как ошибка, очередь продолжается.

`cropped_source` использует устойчивость и ширину контакта с краем, а широкий нижний контакт обычного поясного портрета специально игнорирует; это всё равно эвристика и требует проверки на данных заказчика. QC не заменяет реальный quality test. Качество FP16 против FP32 и пороги следует проверить на фотографиях заказчика. Генеративной дорисовки приложение не выполняет.

## Тесты

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe smoke_test.py
.venv\Scripts\python.exe benchmark.py "D:\Фото" "D:\Benchmark" --count 100
```

Первое проверяет naming, RGBA, разрешение, сохранность исходника, битый файл, resume, routing, Unicode paths, previews и contact sheet. Второе скачивает/загружает BiRefNet и реально выполняет inference на CUDA.
